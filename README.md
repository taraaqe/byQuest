# byQuest 🎮

An interactive city exploration game for students,
developed for the Polaris Media Hackathon 2026.

## About
byQuest is a gamified city exploration app where
students discover new places, complete quests,
earn XP and explore their student city.

## Features
- Interactive city map
- Location-based quests
- XP and progression system
- Local discoveries and challenges

## Tech Stack
- React
- TypeScript
- Vite
